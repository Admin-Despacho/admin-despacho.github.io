OK DESPACHO

Política de privacidad

Última actualización: 31 de octubre de 2026.

1. Alcance

OK Despacho es la aplicación interna de gestión de despacho de OK Accesorios. Esta política describe cómo se tratan los datos en el módulo Comunicaciones, que permite enviar comunicados internos por correo electrónico mediante una cuenta de Gmail conectada y prepararlos para compartir por WhatsApp.

Otros correos de OK Despacho (por ejemplo, avisos de entregas, aprobaciones o informes) se envían mediante un servicio de correo distinto y no usan la cuenta de Gmail conectada. La excepción es el correo de los PDF de las hojas de ruta, que usa la cuenta de Gmail solo si un administrador elige ese canal en la configuración.

Comunicaciones solo está disponible para usuarios de OK Despacho con los permisos correspondientes. Los permisos se controlan en el servidor.

2. Datos que se tratan

Colaboradores (destinatarios)

Para cada colaborador se registran: nombre, correo electrónico, celular, sucursal, sector, si está activo, y qué usuario lo creó o modificó y cuándo. Los colaboradores no necesitan una cuenta en OK Despacho.

Comunicados

Nombre interno, asunto, texto, criterio de destinatarios, programación y versiones. Cada envío guarda una copia del contenido, de la lista de destinatarios y de los adjuntos usados, para que el historial refleje exactamente lo que se envió.

Adjuntos

Se admiten imágenes (PNG, JPG, WEBP, GIF) y PDF. Se guardan en un almacenamiento privado, al que no se accede con un enlace público. El servidor valida el tipo real del archivo y su tamaño. Un adjunto quitado de un comunicado se conserva porque puede formar parte de envíos anteriores.

Historial de envíos

Por cada destinatario: correo, nombre, estado del envío, intentos, errores, el identificador del mensaje que devuelve Gmail y la fecha de envío (informada por Gmail o, si se confirmó manualmente, estimada). Las confirmaciones manuales registran quién las hizo y cuándo.

Auditoría

Se registra qué usuario creó, modificó, programó, pausó, reanudó o canceló un comunicado, y quién conectó o desconectó la cuenta de Gmail, con la fecha.

WhatsApp

OK Despacho no envía mensajes por WhatsApp ni accede a WhatsApp. Solo prepara el texto y los archivos para que la persona los comparta desde su propio dispositivo. Si alguien lo marca manualmente como compartido, se registra quién lo hizo, cuándo y una nota opcional. Ese registro no confirma la recepción.

3. Uso de Gmail y de los datos de Google

Para enviar correos, un administrador autorizado conecta una cuenta de Gmail mediante el inicio de sesión oficial de Google (OAuth). OK Despacho nunca pide ni guarda la contraseña de esa cuenta.

Permisos que se solicitan

  • https://www.googleapis.com/auth/gmail.send: enviar correos en nombre de la cuenta conectada.
  • openid y email: identificar la dirección de la cuenta conectada.

No se solicitan permisos para leer, buscar, modificar ni borrar correos del buzón, ni para acceder a contactos u otros datos de la cuenta. Además se pide acceso sin conexión, para que el servidor pueda enviar los envíos programados aunque la aplicación esté cerrada.

Para qué se usa

  • Enviar los comunicados a los destinatarios elegidos, con un correo individual por destinatario, sin copias visibles a otros.
  • Enviar correos de prueba a la dirección que indique el usuario.
  • Si un administrador lo configura, enviar los PDF de las hojas de ruta del día a los destinatarios definidos en la configuración.

De la cuenta conectada se guardan su dirección de correo, qué usuario la conectó y cuándo, y el estado de la conexión. De cada correo enviado se guarda el identificador que devuelve Gmail.

El uso que OK Despacho hace de la información recibida de las API de Google se ajusta a la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

4. Almacenamiento de credenciales

  • El token de actualización que entrega Google se guarda solo en el servidor, en el almacén de secretos de la base de datos (Supabase Vault). No se guarda en el navegador, en la dirección web, en el código de la aplicación ni en los registros.
  • Los tokens de acceso que se obtienen para enviar se usan solo durante el envío y no se guardan en la base de datos.
  • El navegador nunca recibe tokens de Google. Solo las funciones del servidor pueden leer el token guardado.

5. Dónde se guardan los datos y quién accede

Los datos de Comunicaciones se guardan en la base de datos y el almacenamiento de Supabase, que también ejecuta las funciones del servidor. Los correos se envían mediante Gmail API, de Google. Acceden a los datos los usuarios de OK Despacho con los permisos de Comunicaciones que corresponden a cada acción.

6. Conservación

OK Despacho no elimina automáticamente los datos de Comunicaciones. Colaboradores, comunicados, historial de envíos, auditoría y adjuntos se conservan hasta que se eliminen a pedido.

  • Desactivar a un colaborador lo excluye de los próximos envíos, pero conserva sus datos.
  • Quitar un adjunto de un comunicado conserva el archivo, porque puede formar parte de envíos anteriores.
  • Los archivos que se subieron pero no llegaron a registrarse también se conservan; no hay una limpieza automática.

7. Desconexión de Gmail y eliminación de datos

Desconectar la cuenta de Gmail

  • Un administrador con el permiso correspondiente puede ir a Comunicaciones → Conexión Gmail → DESCONECTAR. Al hacerlo, se borra del servidor el token guardado, se deja de mostrar la cuenta como conectada, se registra en la auditoría y se solicita a Google la revocación del acceso. La aplicación informa si Google confirmó esa revocación.
  • La persona titular de la cuenta de Gmail también puede quitar el acceso en cualquier momento desde la página de permisos de su cuenta de Google.
  • Sin la cuenta conectada, OK Despacho no puede enviar correos por Gmail.

Solicitar la eliminación o corrección de datos

La aplicación no tiene una función para eliminar colaboradores, comunicados, historial o adjuntos. Para pedir el acceso, la corrección o la eliminación de tus datos, escribí a despachoapp26@gmail.com indicando qué datos querés que se revisen. Las solicitudes se atienden manualmente.

8. Cambios en esta política

Si esta política cambia, la versión actualizada se publicará en esta misma página con su nueva fecha.
